# astrbot_plugin_dafeiyu_faces · 随机颜文字

治"只会一张脸"：LLM 回复里的颜文字**同款连用就自动换**。

实测动机：人设里给了整整一库存款（嘴馋/得意/炸毛/委屈/掀桌……），模型一场对话 42 条回复清一色 `(´･ω･`)`——示例列表第一个+百搭害羞脸被锚定后，上下文自强化越用越只用它（与"每次都回 3 条"同一种 LLM 中心倾向病）。提示词防同款条款治标，本插件从机制上兜底。

## 机制：被动换脸（分工）

- **模型管时机和情绪**（它擅长：什么时候配脸、现在是害羞还是嘴馋）
- **库管多样性**（它不擅长）：回复里的颜文字若在该会话**最近 N 条消息**里出现过，就从**同情绪池**随机换一张——位置不动、时机保留，只换脸

## 安全边界（fail-open）

- **只认库内精确匹配的脸**——泛匹配会把（）动作描写误判成颜文字改坏正文；不认识的脸一律放行
- 池里没有别的可选 → 保留原脸
- 任何异常放行原消息，**绝不因换脸吞消息**
- 只处理模型生成文本（`is_model_result`），指令/工具消息不动
- 换脸发生在分段发送等后续处理**之前**（`priority=100`），不影响消息切分

## 配置

| 字段 | 默认 | 说明 |
|---|---|---|
| faces_enabled | `true` | 总开关 |
| faces_packs | `基础,亲密` | **启用包**：基础 / 亲密 / 18+ / 雌小鬼。成年向的 18+、雌小鬼包默认关，有需要自己在列表里加包名；faces_pools 里的自定义池不受包开关影响 |
| faces_repeat_window | `2` | 同一张脸在最近 N 条消息里出现过就换；**0 = 每张都随机**（彻底库发牌） |
| faces_pools | 20 池 167 张 | 每行 `"池名=脸|脸|脸"`；池与池的脸不要重复；条目用成品脸，别手拼乱码 |

默认库分四包（整理自主流颜文字站公开合集——toolneko / lddgo / 豆瓣等，软款审美，人设示例里出现过的款也收进对应池）：

- **基础**（日常）：害羞软乎 / 嘴馋流口水 / 得意开心 / 炸毛生气 / 委屈想哭 / 犯困迷糊 / 惊讶吓到 / 无语汗颜 / 无奈摊手 / 满足享受 / 傲娇哼 / 猫爪蹭蹭 / 加油打气 / 打招呼挥手 / 星星眼期待
- **亲密**（暧昧/RP 过渡带）：比心亲亲 / 暧昧脸红 / 失神迷离——火候分档：日常脸红、暧昧脸红、失神迷离各归各池，连用换脸时调性不掉档
- **18+**（默认关）：沉溺发软——成年向软款（爱心眼发蒙 / 烫红了 / 馋红了），刻意不用 2ch 硬核拟声款（ﾊｧﾊｧ系在现代聊天里出戏）
- **雌小鬼**（默认关）：嚣张欠揍——ｽﾔｧ / 坏笑 / 斜眼那挂

换脸只在同池随机：包没开的池不装载、不参与匹配与替换；一张脸若内嵌在更长的脸里（如 `(´▽`)ﾉ` 里嵌着 `(´▽`)`），只处理最长的那张，防止换短脸把长脸劈坏。

## 指令（仅管理员）

| 指令 | 作用 |
|---|---|
| `/颜文字状态` | 开关/窗口/累计换脸次数/各池张数/最近用脸 |

## 覆盖边界（已知够不着的）

直发不经消息管线的路径换不到：[主动私聊](https://github.com/c29624/astrbot_plugin_dafeiyu_dm)（dafeiyu_dm 直发）、[随机睡觉](https://github.com/c29624/astrbot_plugin_dafeiyu_sleep)的梦话/告别语。这些消息里的颜文字不做处理。

## 生态搭配（同一作者的配套插件）

- [astrbot_plugin_dafeiyu_sleep · 随机睡觉](https://github.com/c29624/astrbot_plugin_dafeiyu_sleep)——作息演出核心：随机入睡/起床、睡眠期守门缓冲、晨间冲刷
- [astrbot_plugin_dafeiyu_dm · 主动私聊——能调工具](https://github.com/c29624/astrbot_plugin_dafeiyu_dm)——晨起/睡前/随机想念三类主动私聊，可挂任意 llm 工具
- [astrbot_plugin_dafeiyu_merge · 私聊聚合](https://github.com/c29624/astrbot_plugin_dafeiyu_merge)——私聊连发合并一次回复 + 分段发送（本插件在它分段之前换脸）

## 实现说明

`on_decorating_result` 钩子（priority=100）扫回复 Plain 里的已知脸：该会话最近 N 条用过的 → 同池随机换（排除最近用过的和本条已用的）；**记账记换后的脸**（用户实际看到的）；状态落盘 `faces_state.json`（每会话最近用脸，最多记 50 个会话）。
